Persistence

Saved to disk, with no library to lean on.

  • 01 A hand-written scanner, parser and writer — ten classes, JDK only.
  • 02 schemaVersion is 1; the file shape is a documented decision, not an accident.
  • 03 Every save writes kitnapper-data.json.tmp first and moves it into place with ATOMIC_MOVE, so a crash leaves the last good file.
  • 04 A corrupt or unreadable save does not strand the user: it falls back to the demo seed (D18).
  • 05 Photos are files in kitnapper-images/, referenced by name — the JSON stays small and readable.

Restart the app and the loan, the freeze and the waive reason are all still there.
