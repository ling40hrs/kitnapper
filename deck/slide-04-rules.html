Where each rule lives

Every rule is implemented once, in the package that owns it.

RuleImplemented byWhat the code does
Who signs in, and what they see User, Borrower, Manager getRole() is implemented per subclass. The shell asks the user object for its role; the session never decides.
What a late return costs FeeStrategy One implementation at ₱50 per day. A second rule is a second class; this one does not change.
Whether a checkout is allowed LoanService Three active loans, due date within fourteen days. An out-of-window date is rejected even though the picker cannot produce one.
Who draws the screen view No reference to service or controller. Screens receive callbacks and return commands.
