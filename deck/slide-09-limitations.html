Limitations

What KitNapper deliberately does not do.

Left outBecause
Damage tracking and damage fees Not in the brief. A return logs a date — a condition grade would be a guess without photos at both ends.
Cancelling a loan, extending a due date The desk's real answer is return-and-reborrow; one fewer state means one fewer way to be wrong.
Multi-user, network or cloud sync One desk, one save file. Concurrency would need a server and a conflict rule we cannot test here.
Production authentication Mock login over the persisted user list; the demo accounts are seeded, not hard-coded.
Installer, code signing, auto-update Out of scope. It runs from NetBeans or build.sh, which is how it will be demonstrated.
Indexed search and reports Filtering is linear over ten items and measures 0.46 ms; an index would be ceremony.

Everything on this page is a recorded decision, not an unfinished edge.
