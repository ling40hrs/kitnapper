Views never import the layers below

A screen declares its own actions; the controller supplies them. The dependency arrow points one way.

Services own every state change

Entities mutate through their own methods. Only services call those methods and DataStore.save().

Exceptions carry meaning

Null, bad value, illegal transition — translated into sentences before they reach the EDT.

A screen never imports the layer below it, so a change in the fee rule cannot break a table.
