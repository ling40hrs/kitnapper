Architecture

Four layers, one direction of dependency.

Views never import the layers below

A screen declares its own action interface — CatalogActions, Sidebar.Callbacks — and the controller supplies it. The dependency arrow points one way.

Services own every state change

Entities mutate through their own methods; only services call those methods and DataStore.save().

Exceptions carry meaning

Null → NullPointerException, bad value → IllegalArgumentException, illegal transition → IllegalStateException. Controllers translate them into sentences before they reach the EDT.

One rule made the rest possible: a screen never imports the layer below it, so a change in the fee rule cannot break a table.
